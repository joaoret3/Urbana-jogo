# Urbana — jogo

Jogo educativo da Escola Municipal Carolina Maria de Jesus (bairro Goiânia, Belo Horizonte).
Esta pasta é a **versão dos alunos** (só o jogo, funciona sem internet) e é gerada automaticamente a partir do repositório de
trabalho `Urbana`. Não edite aqui: as alterações seriam apagadas na próxima publicação.

Versão atual: 2.31. Para jogar: abra o endereço do GitHub Pages deste repositório, ou baixe os arquivos e abra o `index.html`.
Fontes: Londrina Solid e Sedgwick Ave Display (SIL OFL 1.1) — veja `assets/fontes/`.
