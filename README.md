# Urbana — jogo

Jogo educativo da Escola Municipal Carolina Maria de Jesus (bairro Goiânia, Belo Horizonte).
Esta pasta é a **versão dos alunos** (só o jogo, funciona sem internet). Ela é gerada a partir do repositório de trabalho `Urbana`; não edite aqui.

Versão atual: 2.28. Para jogar: abra o endereço do GitHub Pages deste repositório, ou baixe os arquivos e abra o `index.html`.
Fontes: Londrina Solid e Sedgwick Ave Display (SIL OFL 1.1) — veja `assets/fontes/`.
