PASTA DO PROFESSOR, GITHUB E SITE DOS ALUNOS (desde a versão 2.28)
- Esta pasta é a do professor (jogo + Editor de conteúdo + originais/ + cópias de segurança),
  guardada no repositório privado Urbana do GitHub. Antes de editar: Fetch/Pull no GitHub Desktop;
  depois: Commit e Push.
- A cada Push, o GitHub gera sozinho a versão dos alunos (sem editor, originais e cópias de
  segurança) e publica em https://joaoret3.github.io/Urbana-jogo/ (veja docs/COMO-TRABALHAR-COM-GITHUB.md).
- Para computadores sem internet: a versão dos alunos também pode ser baixada do repositório
  Urbana-jogo (botão Code > Download ZIP) e aberta com dois cliques no index.html.

CONTA DE TESTE (desligada nesta pasta)
- Em Novo Jogo, use o apelido TESTE: a partida começa no nível máximo com 9999 latas, para
  experimentar o Black Book, as artes e os muros. Na pasta dos alunos o apelido TESTE é comum
  (ajuste CONTA_TESTE em src/config.js).

COMO ABRIR O JOGO (sem internet, sem instalar nada)
- Celular e tablet: o jogo precisa estar num endereço da web (veja docs/COMO-PUBLICAR-NA-WEB.md).
- Dois cliques em index.html. Use Google Chrome ou Microsoft Edge (atualizados).
- Opcional, para computadores lentos: "Abrir Urbana (Windows).bat" abre o jogo por um
  servidor local, num modo de desenho mais rápido (precisa do Python instalado).
  Atenção: as partidas salvas num modo não aparecem no outro; use Exportar/Importar.

CONTROLES NO MAPA
WASD, setas, joystick (canto inferior esquerdo) ou clique/toque para andar;
E / Espaço / Enter = botão A; B = Black Book; M = missões; P = perfil; N = amplia o mini-mapa; Esc = pausa;
roda do mouse = zoom; C mostra/esconde a colisão (ajuda para quem edita o mapa).

COMO CADASTRAR CONTEÚDO (professores)
Dois cliques em editor.html (o menu do jogo dos alunos não tem link para o editor).
Nele dá para cadastrar grafites e quizzes, artes do Black Book, personagens, missões, níveis e
preços, tutorial e créditos, e posicionar pins, latas, muros, faixas de pedestre e carros no mapa, sem programar. Veja docs/GUIA-DE-CONTEUDO.md.

CONTEÚDO DE EXEMPLO
Tudo que tem "EXEMPLO" no texto é provisório.

CONFERÊNCIA DO CONTEÚDO
Fica só no Editor de conteúdo (aba Conferência): confere ids repetidos, imagens que faltam,
perguntas sem 4 alternativas, preços inválidos, pins, latas e muros fora do mapa ou que não podem
ser alcançados andando a partir da escola, etc. O jogo dos alunos não mostra a conferência.

SALVAMENTO
- Cada computador guarda várias partidas, uma por apelido (máximo em dados/jogo.js).
- O progresso fica no navegador deste computador e é salvo automaticamente.
  Limpar os dados do navegador apaga as partidas: use "Exportar" (em Continuar ou na Pausa)
  para guardar uma cópia em arquivo, e "Importar partida" para trazê-la de volta
  (serve também para levar a partida para outro computador ou para uma nova versão do jogo).
- O jogo guarda a gravação anterior de cada partida; se a atual estragar, ele recupera a anterior.
